## What Went Well

- **Tier-1 vertical slice actually shipped.** Compose → host on GitLab (raw URL) → pin appears on map. The core demo-able path is real, not a mockup.
- **CSP trap caught early.** 9.3 dev notes flagged that `genjson`'s CSP (`default-src 'self'`) blocks Google Fonts CDN — same font-loading pattern the main map uses. Fixed cleanly in 9.5: self-hosted `Special Elite`, operator-locked 2026-05-31, both surfaces switched.
- **Copy stayed SSOT.** `bernard_voice.yaml` remained the single source for wizard copy — consistent with the project-wide rule (no hardcoded JS fallback table). One drift incident (see below) but the model held.
- **Decision-record locking (9.12).** Interaction+visual frame (beats-not-boxes, commit-to-advance, honest derivation, semantic colour) was locked explicitly for 9.6/9.10 to inherit — good practice even though those stories were superseded before consuming it.
- **Supersession discipline held.** Following through on Epic 6's own retro commitment ("enforce supersession at build time"), 9-6/9-7/9-9/9-10 were flipped to `superseded` with dated notes in sprint-status, not left ambiguous.

## What Was Hard

- **Recurring shadow-state drift.** Two separate bugs, same root shape — state duplicated in two places drifts:
  - 9.5: `COPY_FALLBACK` (JS mirror of the YAML) missing `field_hints` → `TypeError` on fetch failure; also diverged wording from approved copy ("the floor" vs "the bedrock").
  - 9.8: wizard close handler didn't reset child beat state on re-open — stale UI, disabled buttons, because beat DOM state and the JS progress model could go out of sync.
- **Mid-epic scope cut.** 4 of 12 stories (9-6, 9-7, 9-9, 9-10 — the Tier 2/3 vision: `mom:` fields, `state.open` FSM, `ext_fab` fields) were superseded by the Epic 6.2 conversational write skillset (2026-06-16 restructure). Not wasted — a better mechanism replaced a planned one — but the wizard's original Tier 2/3 design never got built as speced.
- **9-4 absorption.** Nominatim proxy had to be pulled forward into 9.3 because 9.3 couldn't pass its own E2E acceptance criteria without geocoding — a dependency that should have been visible at story-split time.

## Key Insights (locked)

1. **Superseding wizard Tier 2/3 with a conversational write path was the right call, not a scope failure.** Once a coordinator has a live JSON file, Epic 6.2's bot updates it conversationally — no wizard re-run needed. This mirrors the epics.md rationale and required no fresh architecture decision; it's scope consolidation, not a runtime pivot (contrast with Epic 6→13's genuine architecture shift).
2. **Shadow-state duplication (YAML+JS mirror, or DOM+JS model) is a recurring bug class across this epic.** Two independent incidents, same shape. Worth a standing check on any future stateful wizard-like UI: is there a second copy of state that can silently diverge?
3. **CSP-driven asset constraints (self-hosting fonts, no CDN, same-origin fetch) should be checked at story-split time, not discovered mid-implementation.** 9.3's dev notes caught it before it shipped broken, but it was a near-miss.
