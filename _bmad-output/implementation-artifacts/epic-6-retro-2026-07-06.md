## What Went Well

- **Write path is real and trustworthy.** NL request → `propose_write` (real current/proposed delta) → ✅ reaction → `git_ops.commit_json` → live SHA on GitHub. Confirm-by-construction (no `commit_write` tool in the schema) held end-to-end.
- **Native SDK confirmed sufficient (6-9).** `chat.completions.create(tools=…)` against OpenRouter, ~50-line tool loop. No framework needed to prove the hardest case.
- **AC#10 ground-truth cross-check.** Bernard's confirmed/unconfirmed distinction cross-checked directly against live Oxigraph (via `ssh hetzner`, bypassing the bot) — matched ground truth exactly. Not hallucination, not luck.
- **Model-agnostic fixes discipline.** Nicolas's binding constraint drove PREFIX-injection and prompt-grounding fixes to be correct by construction, not model-tier band-aids.

## What Was Hard

- **Live verification found what tests never would.** 137 green tests coexisted with a live-broken bot. 6-9: 6 live incidents (all plumbing). 6-11: 8 rounds of live debugging; PREFIX root cause found by curling Oxigraph directly.
- **LLM fabricates over failure — recurring class, no code backstop.** Tool-error fabrication (6-9 #4), slug-guessing (6-11 r1), untaken-action claims, log_gap self-report unreliability. Four occurrences, all patched prompt-only.
- **Supersession not enforced at build time.** `nl_to_sparql` (6-4) + `agent.py` (6-9) drifted into prod disagreement; 6-11 spent a full story collapsing them.
- **Ops hazards:** `/app/tasks` had no volume mount → every deploy wiped gap data. Ghost-bot (two processes / one Matrix account) burned two dead-end fixes before root cause surfaced.

---

## Key Insights (locked)

1. **Live verification is the only real DoD for LLM/protocol work.** Green tests ≠ working bot. Institutionalized from Epic 3.5 — keep.
2. **The LLM fabricates over failure; prompt rules are necessary but not sufficient.** No code-level backstop yet → carried as Epic 13 debt (not paid on the retiring harness).
3. **Enforce supersession at build time.** Retire the old path when the new one ships. → Epic 13 adopts twin-until-parity + explicit-retirement discipline.
4. **Build-vs-buy: prototype custom to learn, adopt boring infra to ship.** `harness/` was the right prototype, wrong product — it taught Matrix/E2EE/tool-calling from the inside, which is *why* hermes can now be evaluated rather than cargo-culted. Every hard 6.x problem (6-6/6-8, and 6-9's flagged durable-state gap) is solved-for-free in hermes. "We reinvented a square wheel and got good at pushing it." The pivot is earned, not a reversal.
